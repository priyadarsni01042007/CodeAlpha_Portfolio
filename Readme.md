# 💼 Personal Portfolio Website

A responsive personal portfolio website built using HTML, CSS, and JavaScript to showcase my skills, projects, and learning journey in web development.

## 🚀 Features

* Responsive design for mobile, tablet, and desktop devices
* Modern glassmorphism-inspired user interface
* Smooth navigation between sections
* Skills, Projects, and Contact sections
* Social media integration
* Resume download functionality

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Flexbox
* Media Queries
* Responsive Design

## 📂 Project Structure

Portfolio/

├── index.html

├── style.css

├── script.js

├── images/

└── resume/

## 🎯 Purpose

This portfolio was developed to present my technical skills, projects, and achievements while strengthening my knowledge of frontend web development and responsive design.
